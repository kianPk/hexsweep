# Hexsweep

Hexagonal minesweeper — six-neighbor logic, flags, timer, and win tracking. Built with SVG.

[![Demo](https://img.shields.io/badge/demo-live-0f1a22?style=for-the-badge)](https://kianpk.github.io/hexsweep/)
[![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)](./LICENSE)

## Play

**https://kianpk.github.io/hexsweep/**

## Controls

- Click / tap: reveal
- Right-click / long-press: flag

## Stack

Vanilla JS · HTML5 Canvas/SVG · CSS · GitHub Pages

No frameworks. Runs offline once loaded.

## Local

```bash
python3 -m http.server 8080 --directory docs
# open http://localhost:8080
```
